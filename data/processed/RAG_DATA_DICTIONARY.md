# AvertCare · Leakage-Free RAG Dataset & Feature Data Dictionary

## Executive Overview
This document defines the schema, source, and leakage-prevention protocols for the datasets generated by the AvertCare RAG Engine seeding pipeline (`scripts/seed_rag_engine.py`).

## Target & RAG Feature Definitions

### 1. `readmitted_binary` (Target Variable)
- **Description:** Ground truth 30-day hospital readmission binary indicator.
- **Formula:** `1` if original `readmitted == '<30'`, else `0`.
- **Target Distribution:** ~11.1% positive readmission class across all splits.
- **Scoping Rule:** MUST NEVER enter model feature input matrices. Reserved strictly for ground truth evaluation loss and metrics.

### 2. `clinical_note` (Text Feature)
- **Description:** Synthetic, structured discharge summary synthesized from pre-discharge encounter fields.
- **Target Leakage Prevention:** Contains **0 target-derived words or phrases**. All phrases regarding readmission history or future outcomes were completely removed.
- **Legitimate Inputs Used:** `age_numeric`, `diag_1`, `time_in_hospital`, `number_inpatient`, `number_emergency`, `num_medications`, `change` (medication regimen change status), and randomly assigned SDoH clauses.

### 3. `rag_readmit_rate` (Leakage-Safe RAG Vector Feature)
- **Description:** Historical 30-day readmission rate computed from the top-5 ($K=5$) nearest clinical vector neighbors embedded via `all-MiniLM-L6-v2` SentenceTransformer.
- **Target Leakage Prevention Logic:**
  - **Reference Index:** Indexed ONLY with Training split records (`df_train`). Validation and Test records are NEVER inserted into the reference collection.
  - **Training Split Computation:** For any training query encounter $i$, neighbor search explicitly excludes encounter $i$ AND excludes all encounters matching $i$'s `patient_id` (leave-one-patient-out).
  - **Validation & Test Split Computation:** Query vectors for validation/test encounters search the **Training split vector index ONLY**, excluding any matching `patient_id`.
  - **Value Range:** Strictly bounded within $[0.0, 1.0]$ with 0 null values (defaults to training global mean if no eligible neighbors exist).

### 4. `interventions` (Payload Metadata)
- **Description:** Post-discharge care management interventions.
- **Target Leakage Prevention:** Assigned based on clinical eligibility indicators or randomly assigned to reference cases, completely independent of `readmitted_binary`.

## Excluded Identifiers & Scoping Summary
The following columns are preserved in exported CSV files for traceability and vector search payload metadata, but MUST be excluded from ML feature input matrices:
- `readmitted` (original string label)
- `readmitted_binary` (target label)
- `patient_id` / `patient_nbr` (patient grouping identifier)
- `encounter_id` (encounter identifier)
